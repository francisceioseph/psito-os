# Código de Conduta

O Psito OS adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate todo mundo com respeito, critique ideias e não pessoas, e não tolere assédio de nenhum tipo. Isso vale nas issues, nos pull requests e em qualquer espaço do projeto.

Para relatar um comportamento inaceitável, escreva para o mantenedor pelo e-mail que está nos commits do projeto. Os relatos são tratados com sigilo.
